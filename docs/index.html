Clip Uploader

Ein privates Tool, das Twitch-Clips ins Hochformat schneidet, untertitelt und über die offizielle TikTok Content Posting API auf den eigenen Account des Betreibers hochlädt.

Datenschutz

Das Tool wird nur vom Betreiber für den eigenen TikTok-Account genutzt. Es speichert lediglich ein TikTok-Zugriffstoken (verschlüsselt als GitHub-Secret) und eine Liste bereits hochgeladener Twitch-Clip-IDs. Es werden keine Daten Dritter erhoben, verkauft oder weitergegeben.

Nutzungsbedingungen

Das Tool ist nicht öffentlich nutzbar. Es werden nur Clips von Streamern verwendet, die Clipping erlauben; die Streamer werden in jeder Beschreibung genannt. Auf Wunsch eines Streamers werden dessen Clips sofort ausgeschlossen und entfernt.
